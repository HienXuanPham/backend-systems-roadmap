# Backend Systems Roadmap

A project-based engineering notebook documenting my study of backend
engineering, databases, distributed systems, and cloud infrastructure.

## Goal

My goal is to become a backend software engineer with strong foundations in:

- Go
- operating systems
- Linux
- networking
- databases
- distributed systems
- cloud infrastructure
- reliability
- observability
- system design

## Approach

For each topic I try to:

1. Learn the concept.
2. Explain it in my own words.
3. Implement a small experiment.
4. Apply it to a real project.
5. Test failures and edge cases.
6. Document what I learned.
